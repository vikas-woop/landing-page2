# WOOP Iron Health Landing Page

Responsive static landing page based on the approved WOOP campaign concept.

## Open locally

Open `dist/index.html` in any modern browser.

## Connect the survey

Open `dist/script.js` and replace `https://example.com/health-check` with the live survey or health-check URL. Both CTA buttons will use that link.

## Files

- `dist/index.html` — editable page content
- `dist/styles.css` — layout, colours, typography and responsive styling
- `dist/script.js` — CTA destination
- `dist/assets/woop-logo.png` — supplied WOOP logo
- `dist/assets/mother-child-gift.png` — campaign hero visual
